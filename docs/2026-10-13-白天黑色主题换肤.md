# 2026-10-13 更新：白天／黑色主题换肤

## 功能说明

应用新增应用级明暗主题，默认保持原有白天界面，用户可从常驻侧边导航底部随时切换黑色主题：

- 主题状态由 `App.vue` 唯一维护，通过根节点 `<html data-theme="light|dark">` 切换整套 CSS 变量，不向子组件逐层传递
- 选择以 `app_theme` 存入 localStorage，刷新页面或重启桌面应用后继续生效；无记录、非法值或存储不可用时回退白天主题
- 切换时同步更新 `meta[name="theme-color"]` 与 `color-scheme`，原生输入框、下拉框、复选框随主题适配
- 切换主题不重置当前视图、股票查询、报告筛选、分页或正在运行的任务状态
- 侧边栏主题按钮为原生按钮，带 `aria-pressed`、动态 `title` 和图标 `aria-hidden`；桌面端位于导航底部，窄屏（760px 以下）固定在顶部横向导航最右侧并只显示图标

涉及文件：`frontend/src/App.vue`、`frontend/src/utils/storage.ts`

## 暗色样式覆盖

`style.css` 在保留浅色视觉的前提下扩充了语义化颜色变量（表面、控件、文字、边框、阴影、主色交互、成功／警告／错误／中性状态、AI 渐变、综合评估、引用块、滚动条），并在 `:root[data-theme="dark"]` 中提供接近黑色但非纯黑的暗色值：

- 全局替换硬编码浅色：页面、卡片、侧边导航 hover/active、输入框与 placeholder、标签、进度条、错误／成功／警告提示、实时／缓存徽标
- Markdown 渲染区（`marked` + DOMPurify 输出）的表格表头、内联代码、代码块、引用块改用主题变量
- 综合评估高亮卡片、章节目录高亮与圆点、数据源异常折叠块同步换肤
- 滚动条（标准 `scrollbar-color` 与 WebKit）随主题配色；键盘焦点统一 `:focus-visible` 轮廓
- `--up`／`--down` 仅保留 A 股红涨绿跌语义，通用成功／失败改用独立状态变量，避免设置页与错误提示语义混乱
- 日期选择器（`@vuepic/vue-datepicker`）补齐背景、文字、边框、hover、选中、禁用、图标、滚动条等变量映射

涉及文件：`frontend/src/style.css`、`frontend/src/components/ReportList.vue`、`frontend/src/components/DataSourceBanner.vue`、`frontend/src/components/SettingsPanel.vue`、`frontend/index.html`

## 设计取舍

- 不跟随系统主题，主题只由用户手动切换并持久化，避免系统外观变化导致应用突然换肤
- 不引入状态库、新依赖或独立 composable，主题逻辑只有「读取、应用、保存、切换」四步，放根组件与现有存储封装即可
- 不修改 Tauri Rust 与原生窗口配置，macOS 原生标题栏继续遵循系统默认外观；未做整页颜色过渡动画，避免大面积换肤闪烁
