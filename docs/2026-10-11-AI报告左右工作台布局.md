# 2026-10-11 AI 报告改为左侧边栏 + 右侧内容布局

## 用户需求

AI 全维度分析的报告展示区改成与「全维度数据」工作台相同的模式：左边是章节侧边栏，右边是内容区。

## 修改内容

### 前端 `frontend/src/components/AiReport.vue`

- 报告展示区从「横向目录条 + 纵向章节流」重构为左右工作台布局，复用 `FullDataPanel` 的 `data-workbench` / `data-sidebar` / `data-chapter-nav` / `data-content` 类与样式，保证两个面板视觉一致
- 左侧边栏：sticky 固定的十二章目录，「十、综合评估」以紫色高亮（`is-summary` 类）与其他章节区分
- 右侧内容区：综合评估高亮卡片置顶，其余章节按原规则展示（AI 点评默认展开、数据表格折叠）
- 卡片头部（标题、触发开关、提示、生成按钮、进度区）包进 `.ai-report-head`；元信息（缓存标记/时间/模型/tokens/重新生成）保持在工作台上方横条
- 删除原横向 `chapter-nav` 目录条（被侧边栏取代），进度区的章节状态 chip 保留

### 样式 `frontend/src/style.css`

- 新增「AI 报告左右工作台」段：`.ai-report` 卡片去内边距（与工作台一致）、`.ai-report-head` 内边距、警告/错误/元信息横条的 20px 外边距、综合评估目录项紫色高亮
- 删除已无元素引用的 `.chapter-nav` 两段样式（横向目录条）
- 移动端（≤760px）适配：侧边栏变为顶部横向滚动目录（复用现有 media query），补充 ai-report 系列内边距规则

## 验证

- `vue-tsc --noEmit` 通过
- `npm run build` 构建成功

## 备注

工作台网格（190px 侧边栏 + 内容区）、移动端横向目录等交互行为与「全维度数据」面板完全一致，用户无需重新学习。
