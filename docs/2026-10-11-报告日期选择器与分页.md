# 2026-10-11 更新：报告日期选择器与服务端分页

## 日期筛选改为日期选择器

「已生成的报告」不再用日期下拉列表，改为 `@vuepic/vue-datepicker` 中文单日日期选择器：

- 支持日历弹层选择和一键清空
- 前端模型固定使用 `yyyy-MM-dd` 字符串，避免 JavaScript 日期时区转换导致前后偏移一天
- 清空日期后恢复显示全部日期
- 选择或清空日期后自动回到第 1 页
- 日期组件样式与现有输入框、主题色保持一致

涉及文件：`frontend/src/components/ReportList.vue`、`frontend/package.json`、`frontend/package-lock.json`

## 报告表格改为服务端分页

报告列表 API 与前端表格同步增加分页，默认每页 10 条：

- `GET /api/report/list` 新增 `page`（默认 1）与 `page_size`（默认 10，最大 100）
- 日期参数改由 FastAPI 按真实日期校验，非法日期和非法页码在进入查询前返回 422
- SQLite 查询先按相同筛选条件统计 `COUNT(*)`，再用参数化 `LIMIT/OFFSET` 获取当前页
- 响应新增 `total`、`page`、`page_size`、`total_pages`
- 页码超出末页时自动回到最后一个有效页；无结果时统一返回第 1 页、总页数 0
- 前端提供上一页、页码和下一页；页数较多时折叠为当前页附近页码和省略号
- 日期或行业改变后回到第 1 页，刷新按钮保留当前筛选和页码
- 快速切换筛选或页码时会中止旧请求，并防止旧请求提前结束新请求的加载状态
- 表格在窄屏下支持横向滚动，筛选栏和分页栏自动换行

涉及文件：`backend/app/api/report_routes.py`、`backend/app/services/report_index.py`、`frontend/src/api/client.ts`、`frontend/src/api/types.ts`、`frontend/src/components/ReportList.vue`
