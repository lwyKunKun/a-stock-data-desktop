# 2026-10-11 更新：查询持久化、历史记录、数据源版本监控与一键更新报告

## 新增功能

### 1. 查询持久化（刷新不丢）

查询成功后，股票代码写入浏览器 localStorage（`last_query_code`）；刷新页面后自动恢复上次查询。后端全维度数据按日缓存，恢复后面板直接命中缓存秒开，无需重复采集。

涉及文件：`frontend/src/App.vue`、`frontend/src/utils/storage.ts`

### 2. 查询历史记录

搜索框下方新增历史栏，最多保留 20 条（代码 + 名称 + 时间），按代码去重、最新在前，存 localStorage 刷新不丢。支持点击标签重新查询、单条删除、一键清空。

涉及文件：`frontend/src/components/HistoryBar.vue`、`frontend/src/utils/storage.ts`

### 3. 数据源版本监控横幅

后端跟踪上游数据源仓库 [simonlin1212/a-stock-data](https://github.com/simonlin1212/a-stock-data) 的最新提交，与本地已确认版本对比；有新提交且未确认时，页面顶部显示提醒横幅。点「知道了」确认后不再提示，直到上游再次更新。

- 接口：`GET /api/datasource/status`、`POST /api/datasource/ack`
- GitHub API 结果带 10 分钟服务端缓存，不会触发每小时 60 次的未认证限流
- 确认状态持久化在 `backend/data/datasource_version.json`
- GitHub 不可达时接口安全降级，不影响其他功能

涉及文件：`backend/app/services/datasource_watch.py`、`backend/app/api/datasource_routes.py`、`frontend/src/components/DataSourceBanner.vue`

### 4. 一键生成更新报告

横幅上的「生成更新报告」按钮：后端通过 GitHub compare API 生成「已确认版本 → 最新版本」的函数级差异报告，并自动映射到后端移植文件。零 token、确定性逻辑，不自动改写任何代码。

报告内容：

- 提交列表（带链接）
- 对后端移植代码的影响：哪个后端文件涉及哪些函数（扫描 `app/core` 与 `app/datasources` 的函数索引与上游 diff 匹配）
- 上游新增/变更、后端尚未接入的函数清单
- 每个变更文件的折叠 diff 面板（补丁截断至 40 行）

其他细节：

- 接口：`POST /api/datasource/report`，报告按 `base...head` 版本对磁盘缓存（`backend/data/datasource_report.json`），重复点击不重复请求
- 从未确认过基线时自动退回只对比最新一次提交；已确认基线被 force-push 删除时同样兜底
- 看完报告后在对话中让 Claude 按报告完成移植，再点「知道了」确认基线

> 设计说明：后端取数代码是从上游 SKILL.md 移植改造的（仅 `app/core/ticker.py` 逐段移植），与上游文件不一一对应，无法直接 `git pull` 覆盖，因此一键更新只做报告提醒，不做自动合并。

## 修复：虚拟环境失效

项目目录从 `~/stock-app` 改名为 `~/a-stock-data-desktop` 后，旧 `.venv` 内 pip 的解释器路径仍指向已不存在的旧目录，导致 venv 内 pip 失效、安装命令回落到全局 Python 触发 externally-managed 报错。已用 `python3 -m venv --clear .venv` 重建并重装依赖，19 项测试全部通过。README 中的启动路径同步更正。
